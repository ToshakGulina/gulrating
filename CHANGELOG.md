# История изменений

Изменения сгруппированы по опубликованным версиям. Полный технический журнал доступен в истории Git.

## Не опубликовано

- История поиска хранит не более трёх текстовых запросов, чтобы освободить место для плиток недавно открытых тайтлов.
- В настройках можно объединить оценки одного тайтла разных пользователей в одной карточке ленты.
- Состав и порядок разделов ленты настраиваются только в профиле; можно скрывать/показывать «Тренды», «Подборки» и «Оценки».
- Уменьшены постеры ленты на телефонах; сетка трендов адаптирует количество столбцов и показывает только полные ряды.
- Администратор может выдавать и снимать права администратора, одобрять и отзывать доступ пользователей.
- В профиле есть отдельный раздел «Просмотрено»: для сериалов отслеживаются новые сезоны и серии, для фильмов — новые части в коллекции TMDb; о новинках приходят уведомления.
- Добавлены мягкие анимации появления разделов, карточек, результатов поиска, окон, навигации, заставки и уведомлений; интерактивные элементы получили аккуратную обратную связь. Учитывается системная настройка «Уменьшить движение».
- Настройки профиля вынесены в отдельный раздел. Переключение между лентой и профилем теперь сохраняет открытые вкладки, фильтры, поисковый запрос и прокрутку без повторного построения страницы.
- Карточки объединённых оценок упрощены до средней оценки и компактного ряда аватаров; подробности открываются в карточке тайтла. Постеры ленты и истории стали крупнее, а поля и кнопки получили более цельные скругления.
- Добавлены анимация открытия карточки тайтла, заметная кнопка «Смотреть», полноэкранный режим для всего оверлея плеера и необязательная вертикальная обрезка краёв встроенного источника.
- На сайте зеркало со всеми источниками, включая Alloha и Turbo, открывается внутри окна плеера с кнопкой закрытия X — GulRating остаётся на месте. В APK зеркало по-прежнему открывается напрямую.

## [1.0.21] — 2026-10-16

- Исправлен запасной Kinobox proxy: при ограничении прямых запросов встроенный плеер снова получает список источников.
- Увеличены постеры карточек; история поиска стала компактной горизонтальной лентой.
- APK будет подписан новым ключом. Для установки поверх старой версии потребуется сначала удалить предыдущий APK; локальные данные перед этим следует синхронизировать.

## [1.0.20] — 2026-10-16

- Исправлен запуск: восстановлен отсутствовавший экспорт карточки, из-за которого приложение оставалось на заставке.
- APK получил встроенную копию веб-оболочки для старта при недоступности основного адреса.
- Добавлена синхронизация истории и настроек аккаунта между устройствами после установки миграции `supabase-user-sync.sql`.
- Усилена работа офлайн-кэша и обновлена метка сборки до `2026.10.16-63`.

## [1.0.19] — 2026-10-16

- Первая сборка APK со встроенной веб-оболочкой и начальной версией синхронизации данных.
- В следующем выпуске исправлена ошибка запуска, найденная после публикации этой версии.

## [1.0.18] — 2026-10-16

- APK возвращён к проверенной схеме просмотра через страницу зеркала, чтобы сохранить совместимость источников.
