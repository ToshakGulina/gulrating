# История изменений

Изменения сгруппированы по опубликованным версиям. Полный технический журнал доступен в истории Git.

## [1.0.20] — 2026-10-16

- Исправлен запуск: восстановлен отсутствовавший экспорт карточки, из-за которого приложение оставалось на заставке.
- APK получил встроенную копию веб-оболочки для старта при недоступности основного адреса.
- Добавлена синхронизация истории и настроек аккаунта между устройствами после установки миграции `supabase-user-sync.sql`.
- Усилена работа офлайн-кэша и обновлена метка сборки до `2026.10.16-63`.

## [1.0.19] — 2026-10-16

- Первая сборка APK со встроенной веб-оболочкой и начальной версией синхронизации данных.
- В следующем выпуске исправлена ошибка запуска, найденная после публикации этой версии.

## [1.0.18] — 2026-10-16

- APK возвращён к проверенной схеме просмотра через страницу зеркала, чтобы сохранить совместимость источников.
