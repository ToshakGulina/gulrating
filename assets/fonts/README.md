# Локальный шрифт Inter

Файлы взяты из пакета [`@fontsource/inter` 5.3.0](https://www.npmjs.com/package/@fontsource/inter) и включают только обычные начертания 400, 500, 600 и 700 для кириллицы и латиницы. Лицензия SIL Open Font License 1.1 находится в `OFL.txt`.

Шрифт загружается с того же домена, что и приложение, и включён в PWA-кэш — Google Fonts и интернет для отображения интерфейса не нужны.
