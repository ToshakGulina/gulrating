# GulRating — прогресс плееров

WebExtension сохраняет и восстанавливает позицию просмотра в HTML5-видео у поддерживаемых Kinobox-плееров. Это нужно в браузере: GulRating не может читать `<video>` внутри стороннего iframe из-за same-origin policy. Расширение читает только `currentTime` и `duration`, а историю сохраняет сама страница GulRating в своём локальном профиле.

Расширение запускается только на перечисленных player-origin доменах, в том числе во вложенных iframe: `stravers.live`, `alloha.tv`, `alloha.cool`, `obrut.show`, `kodik.info`, `kodik.cc`, `kodik.club`, `kodik.ws`, `videocdn.net`, `videocdn.tv`, `collaps.me`, `collaps.so`, `bazon.cc`, `hdzo.fun`, `kurolesya.link`, `nextembed.ws`, `kinokino.vip`, `kinobox.tv` и `vidlink.pro` (включая их поддомены). Если у конкретного источника видео размещено на другом домене или он не использует доступный HTML5 `<video>`, источник потребует отдельной адаптации.

Скрипт передаёт время только открытой странице GulRating на `gulrating.pages.dev` (включая preview-поддомены) или localhost для разработки, и только после проверки запроса на продолжение. Данные не отправляются на сторонний сервер. Расширение не запрашивает разрешения на чтение истории браузера, аккаунта, оценок или паролей. При обновлении браузер может запросить доступ к новым доменам плееров из списка выше.

## Установка

Один и тот же Manifest V3 пакет совместим с Chromium и Firefox; Firefox ID сохранён, чтобы обновление заменяло установленную версию, а не создавало второе расширение.

- **Chrome / Edge:** открыть страницу расширений, включить режим разработчика, выбрать «Загрузить распакованное» и указать эту папку.
- **Firefox для проверки:** открыть `about:debugging#/runtime/this-firefox`, нажать «Загрузить временное дополнение…» и выбрать `manifest.json` из этой папки. Временное дополнение удаляется после перезапуска Firefox.
- **Firefox для постоянной установки:** пакет должен быть подписан Mozilla. Собрать XPI можно командой `sh browser-extension/alloha-progress/package-firefox.sh`; затем загрузить его в Mozilla Add-ons для проверки/подписи. Публикация в каталоге требует аккаунта владельца расширения и в этом репозитории автоматически не выполняется.

Firefox 109 или новее нужен для Manifest V3.

## Проверка работы

1. Установить или обновить расширение и разрешить доступ к нужному домену плеера.
2. Открыть GulRating и запустить поддерживаемый источник.
3. Во время воспроизведения расширение передаёт позицию странице GulRating; после переключения на другой источник или повторного открытия тайтла позиция должна сохраниться.
