# GulRating — прогресс Alloha

Небольшое WebExtension-расширение для браузера. Оно запускается только во фреймах Alloha/Stravers, находит HTML5-видео и передаёт время просмотра открытой странице GulRating. Само по себе расширение не загружает видео, не меняет озвучку и не отправляет историю на сторонний сервер: позицию сохраняет сайт GulRating по своим обычным правилам синхронизации.

Поддерживаемые сейчас origins: `stravers.live`, `*.stravers.live`, `alloha.tv`, `*.alloha.tv`, `alloha.cool`, `*.alloha.cool`. Скрипт работает только при просмотре через `gulrating.pages.dev` (включая его preview-поддомены) и на localhost для разработки.

## Установка

Один и тот же Manifest V3 пакет совместим с Chromium и Firefox: расширение не использует специфичные API Chrome; Firefox ID и минимальная версия Gecko заданы в `manifest.json`.

- **Chrome / Edge:** открыть страницу расширений, включить режим разработчика, выбрать «Загрузить распакованное» и указать эту папку.
- **Firefox для проверки:** открыть `about:debugging#/runtime/this-firefox`, нажать «Загрузить временное дополнение…» и выбрать `manifest.json` из этой папки. Временное дополнение удаляется после перезапуска Firefox.
- **Firefox для постоянной установки:** пакет должен быть подписан Mozilla. Собрать XPI можно командой `sh browser-extension/alloha-progress/package-firefox.sh`; затем загрузить его в Mozilla Add-ons для проверки/подписи. Публикация в каталоге требует аккаунта владельца расширения и в этом репозитории автоматически не выполняется.

Firefox 109 или новее нужен для версии Manifest V3. Расширение не собирает историю браузера и не запрашивает разрешений на чтение данных аккаунта.

## Проверка работы

1. Установить расширение и открыть GulRating.
2. Открыть «Дюна» и выбрать Alloha / нужную озвучку.
3. Внизу оверлея должно появиться сообщение «Расширение GulRating подключено…».
4. После просмотра позиция появится в истории и будет доступна для продолжения при следующем открытии.

Расширение не получает доступ к TMDb, Supabase, оценкам, паролю или аккаунту. У него нет фонового процесса и разрешений на чтение истории браузера.
