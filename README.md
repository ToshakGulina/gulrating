# 🎬 Кинопоиск для друзей
Приложение для совместной оценки фильмов и сериалов в кругу друзей. Полностью бесплатное в использовании, не требует серверов и регулярных оплат, работает на любых устройствах из браузера.

## 📋 Что умеет (уже реализовано и полностью работает)
- ✅ Поиск фильмов и сериалов по базе TMDB (более 800 тыс. тайтлов) с автодополнением при вводе (показывается постер и год, чтобы не перепутать одноименные фильмы)
- ✅ Автоматическая загрузка постера, года выхода, жанров, описания и рейтинга TMDb при добавлении фильма
- ✅ Общая лента оценок друзей с комментариями, показом кто и когда поставил оценку
- ✅ Фильтры ленты: все оценки / только фильмы / только сериалы / мои оценки / список "Хочу посмотреть"
- ✅ Личный профиль со статистикой (количество оценок, средняя оценка, количество запланированных к просмотру)
- ✅ Личный список просмотренного и список "Хочу посмотреть"
- ✅ Адаптивный интерфейс для телефонов, планшетов и компьютеров
- ✅ Система доступа: пользователи регистрируются по ссылке на почту, администратор одобряет им доступ в один клик — посторонние не попадут
- ✅ Реалтайм синхронизация данных между всеми устройствами (новые оценки появляются сразу без перезагрузки страницы)
- ✅ Карточка каждого фильма показывает оценки всех друзей и среднюю оценку в вашей компании
- ✅ Возможность редактировать и удалять свои оценки
- ✅ Возможность добавить приложение на главный экран телефона как обычное приложение (PWA)
- ✅ Экспорт всех данных в JSON для бэкапа в один клик для администратора
- ✅ Авторизация по магической ссылке на почту — не нужно запоминать пароли, вход в один клик
- ✅ Работает без VPN, не привязан к Телеграму, открывается в любом браузере на любом устройстве
- ⏳ Опциональный Телеграм-бот с уведомлениями (можно добавить позже при желании)

## 🚀 Быстрый старт (15 минут, не требует знаний программирования)

### Шаг 1: Получаем API ключ для базы фильмов (2 минуты)
1. Откройте https://www.themoviedb.org/signup и зарегистрируйтесь (бесплатно, карта не нужна)
2. После регистрации зайдите в Настройки → API → Запросить ключ API (выберите "Developer" вариант, заполните форму в свободной форме, можно по-русски)
3. Скопируйте полученный `API Key (v3 auth)` — он понадобится дальше.

### Шаг 2: Настраиваем базу данных и авторизацию (7 минут)
1. Откройте https://supabase.com/dashboard/sign-up и зарегистрируйтесь через Гитхаб или почту (бесплатно, карта не нужна)
2. Создайте новый проект (название любое, например `GulRating`, регион выберите **Central EU (Frankfurt) eu-central-1** — он самый быстрый и стабильный для доступа из России), пароль от базы можете не сохранять, он не понадобится
3. Дождитесь запуска проекта (занимает ~2 минуты, страница сама обновится когда проект будет готов)
4. Зайдите в раздел слева `SQL Editor` → нажмите `New query` в правом верхнем углу, вставьте туда весь текст из файла `supabase-schema.sql` из этого проекта, нажмите `Run` в правом нижнем углу — у вас автоматически создадутся все нужные таблицы, права доступа и триггеры.
5. Зайдите в раздел слева `Authentication` → `Providers` → выберите `Email`, отключите опцию `Confirm email` (чтобы не ждать подтверждения почты при входе), нажмите Save.
6. В том же разделе `Authentication` пролистайте до `URL Configuration`, добавьте в Redirect URLs адрес `http://localhost:8000` (для локального тестирования) и потом добавите адрес сайта после деплоя, нажмите Save.
7. Зайдите в раздел слева `Settings` → `API`, скопируйте два значения: `Project URL` и `anon public` key — они понадобятся дальше.

### Шаг 3: Запускаем приложение локально (3 минуты)
1. Откройте файл `src/config.js` и вставьте туда ваши 3 ключа (Project URL, anon key из Supabase и API ключ из TMDb), больше ничего в коде менять не нужно.
2. Запустите локальный сервер: откройте терминал в папке проекта и выполните команду:
   ```bash
   npx serve .
   ```
   Если попросит установить `serve` — нажмите Y и подождите.
3. Откройте в браузере адрес `http://localhost:8000`
4. Введите свою почту, на нее придет ссылка для входа. Первый зарегистрированный пользователь автоматически становится администратором и получает полный доступ сразу.
5. Чтобы пригласить друзей просто разошлите им ссылку на ваш сайт, после того как они зарегистрируются вы увидите их в разделе Профиль и сможете одобрить доступ в один клик.

### Шаг 4: Деплой на бесплатный хостинг (3 минуты, чтобы сайт был доступен из интернета всем друзьям)
1. Залейте папку с проектом в любой репозиторий GitHub (создайте бесплатный аккаунт если его нет)
2. Откройте https://pages.cloudflare.com/, нажмите `Sign up` и зарегистрируйтесь через Гитхаб (бесплатно, карта не нужна)
3. Нажмите `Create a project` → `Connect to Git`, выберите ваш репозиторий с проектом
4. В настройках деплоя укажите:
   - Build command: оставьте полностью пустым
   - Output directory: укажите `/` (корень репозитория)
5. Нажмите `Save and Deploy` — через минуту ваше приложение будет доступно по бесплатному адресу вида `kino-druzey.pages.dev`
6. Вернитесь в настройки Supabase (шаг 2.6) и добавьте этот адрес в Redirect URLs, чтобы вход по почте работал и на продакшене.

## 💡 Как пользоваться
1. Вводите название фильма или сериала в поиске сверху — появятся варианты с постерами и годом
2. Выберите нужный вариант, поставьте оценку от 1 до 10, по желанию добавьте комментарий
3. Можете добавить фильм в список "Хочу посмотреть" если не смотрели его еще
4. В ленте будут появляться оценки всех ваших друзей сразу как только они их поставят
5. В профиле можно посмотреть свою статистику, список своих оценок и запланированных фильмов
6. Если вы админ — в профиле вы видите новые заявки на доступ и можете одобрять их в один клик, а также делать бэкап всех данных в JSON файл

## 🛠️ Стек
- Ванильный HTML/CSS/JS (тяжелые фреймворки не нужны, приложение загружается за 500 мс даже на медленном интернете)
- Supabase — база данных, авторизация, реалтайм синхронизация
- TMDb API — база данных фильмов и сериалов
- Tailwind CSS — стили
- Cloudflare Pages — бесплатный хостинг

## 📱 Как добавить приложение на главный экран телефона
- **На Android**: откройте сайт в Chrome, нажмите на три точки в правом верхнем углу → "Добавить на главный экран"
- **На iOS**: откройте сайт в Safari, нажмите на кнопку "Поделиться" → "Добавить на экран «Домой»"

После этого приложение будет открываться как отдельное, без панели браузера, и выглядеть точно так же как нативное приложение из магазина.

## 🤖 Опциональный Телеграм-бот
После запуска основного сайта можно за 10 минут добавить бота, который будет присылать уведомления о новых оценках и позволит ставить оценки прямо из Телеграма. Инструкция будет добавлена после запуска основной версии.
