# 🎬 Кино для друзей (GulRating)
Приложение для совместной оценки фильмов и сериалов в кругу друзей. Полностью бесплатное в использовании, не требует серверов и регулярных оплат, работает на любых устройствах из браузера, ставится на главный экран телефона как приложение (PWA) без публикации в App Store / Google Play.

## 📋 Что умеет
- ✅ Поиск фильмов и сериалов по базе TMDb (более 800 тыс. тайтлов) с автодополнением: постер и год, чтобы не перепутать одноимённые фильмы
- ✅ Автоматическая загрузка постера, года выхода, жанров, описания и рейтинга TMDb при добавлении фильма
- ✅ Общая лента оценок друзей с комментариями: видно, кто и когда поставил оценку
- ✅ Фильтры ленты: все оценки / только фильмы / только сериалы / мои оценки / «хочу посмотреть» всей компании
- ✅ Карточка фильма: оценки всех друзей и средняя оценка в вашей компании
- ✅ Оценка 1–10, комментарий, изменение и удаление своей оценки
- ✅ Список «Хочу посмотреть» (добавление/удаление в один клик)
- ✅ Личный профиль со статистикой: количество оценок, средняя оценка, сколько в планах
- ✅ Система доступа: вход по магической ссылке на почту, администратор одобряет новых участников в один клик — посторонние не попадут
- ✅ Реалтайм: новые оценки появляются у всех сразу, без перезагрузки страницы
- ✅ PWA: установка на главный экран телефона (Android и iOS), работа офлайн (оболочка приложения)
- ✅ Бэкап всех данных в JSON в один клик для администратора
- ✅ Тёмная адаптивная вёрстка под телефоны, планшеты и компьютеры
- ✅ Опциональный прокси TMDb через Cloudflare Worker, если api.themoviedb.org блокируется провайдером (см. `optional/tmdb-proxy-worker.js`)
- ⏳ Опциональный Телеграм-бот с уведомлениями (можно добавить позже при желании)

## 🧰 Стек
- Ванильный HTML/CSS/JS + Tailwind CSS (без сборки: приложение загружается мгновенно)
- Supabase — база данных, авторизация по магическим ссылкам, реалтайм, политики доступа (RLS)
- TMDb API — база фильмов и сериалов
- Cloudflare Pages — бесплатный статический хостинг

## 🚀 Быстрый старт

### Что уже настроено в этом репозитории
| Параметр | Значение | Где лежит |
|---|---|---|
| Supabase Project URL | `https://ahpgxyfkbvuabgtrgacu.supabase.co` (регион Frankfurt) | `src/config.js` |
| TMDb API Key (v3) | вшит | `src/config.js` |
| Supabase anon key | **нужно вставить один раз** | `src/config.js` → `SUPABASE_ANON_KEY` |

> Пока anon key не вставлен, приложение не падает, а показывает экран-подсказку с инструкцией, какие поля заполнить.

### Шаг 1. База данных в Supabase (5 минут)
1. Откройте дашборд проекта Supabase → **SQL Editor** → **New query**.
2. Вставьте туда **весь** файл `supabase-schema.sql` и нажмите **Run**.
   Скрипт идемпотентный: его можно запускать повторно, ничего не сломается. Он создаёт таблицы `profiles`, `titles`, `ratings`, `watchlist`, политики RLS, триггер автоматического создания профиля и включает реалтайм.
3. **Authentication → Providers → Email** → выключите **Confirm email** → Save. Иначе вход по магической ссылке будет требовать ещё и подтверждения письма.
4. **Authentication → URL Configuration → Redirect URLs** добавьте:
   - `http://localhost:8000` — для локальных тестов;
   - адрес продакшена после деплоя (шаг 4);
   - адрес предпросмотра Arena/песочницы, если тестируете оттуда.
5. **Settings → API**: скопируйте **anon public** key.

### Шаг 2. Ключ в конфиге (1 минута)
В файле `src/config.js` замените плейсхолдер:
```js
SUPABASE_ANON_KEY: "сюда_вставьте_anon_key_из_supabase",
```
Это единственный ключ, который нужно вставить руками. URL Supabase и ключ TMDb уже вписаны.

> 💡 **Быстрый тест без правки кода:** если открыть сайт до вставки ключа, появится экран «Приложение не настроено» с полем, куда anon key можно вставить прямо из браузера — он сохранится в localStorage этого браузера. Это удобно для проверки и предпросмотра; для продакшена ключ всё равно впишите в `src/config.js`, чтобы он работал у всех друзей сразу.

> 🔐 **Почему ключ в коде — это нормально:** `anon` ключ Supabase задуман публичным. Реальную защиту данных обеспечивают политики RLS в базе (см. `supabase-schema.sql`): не одобренный админом пользователь не увидит ни одной оценки. То же касается ключа TMDb — это обычный ключ чтения каталога фильмов.

### Шаг 3. Локальный запуск (2 минуты)
```bash
npx serve .
# или, если нет node:
python3 -m http.server 8000
```
Откройте `http://localhost:8000`, введите почту и перейдите по присланной ссылке. **Первый зарегистрированный пользователь автоматически становится администратором** и получает доступ сразу. Друзьям достаточно ссылки на сайт: они попадут в список заявок, вы одобрите их в Профиле в один клик.

### Шаг 4. Деплой на Cloudflare Pages (3 минуты)

> ⚠️ **САМОЕ ВАЖНОЕ:** при подключении репозитория выбирайте **Cloudflare Pages (статический сайт)**, а **НЕ Cloudflare Workers**. Ошибка прошлого деплоя возникла именно из-за выбора типа Workers. Файлы `_redirects` и `_headers` в корне — это штатные фичи **Pages** (SPA-роутинг и заголовки кэширования); в Workers они не поддерживаются, поэтому там и была ошибка. Удалять их не нужно.

1. https://pages.cloudflare.com → **Sign up** через GitHub (бесплатно, карта не нужна).
2. **Create a project** → **Connect to Git** → выберите репозиторий `ToshakGulina/gulrating` и ветку, из которой деплоите (обычно `main`).
3. В настройках сборки укажите:
   - **Framework preset:** `None`
   - **Build command:** оставьте полностью пустым
   - **Output directory:** `/` (корень репозитория)
4. **Save and Deploy** — через минуту сайт будет доступен по адресу вида `gulrating.pages.dev`.
5. Вернитесь в Supabase → **Authentication → URL Configuration** и добавьте адрес `https://gulrating.pages.dev` в **Redirect URLs**, иначе вход по почте на проде не сработает.

**Деплой из терминала (альтернатива):** если не хочется подключать Git в дашборде,
```bash
npx wrangler pages deploy . --project-name=gulrating
```
(воркер/секреты не нужны — это чисто статический деплой).

### Шаг 5 (опционально). Прокси TMDb, если база фильмов не открывается
У некоторых провайдеров `api.themoviedb.org` периодически недоступен. В этом случае:
1. Создайте Worker в Cloudflare (Workers & Pages → Create → Worker), вставьте код из `optional/tmdb-proxy-worker.js`, задеплойте.
2. В настройках воркера добавьте секрет `TMDB_API_KEY`.
3. В `src/config.js` впишите адрес воркера в `TMDB_PROXY_URL`.
Приложение само начнёт ходить за фильмами через прокси, ничего больше менять не нужно.

## 🧯 Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| Белый экран / экран «Приложение не настроено» | Не заполнен `SUPABASE_ANON_KEY` в `src/config.js`. Вставьте ключ и обновите страницу. |
| Экран «Профиль не создан» | В Supabase не запущен `supabase-schema.sql` (или аккаунт создан до запуска скрипта). Запустите скрипт; для уже существующих пользователей выполните в SQL Editor: `SELECT public.repair_missing_profiles();` |
| «Доступ ожидает подтверждения» | Так и задумано: админ должен одобрить вас в Профиле → Управление доступом. |
| Письмо со ссылкой не приходит | Проверьте «Спам». Убедитесь, что выключен **Confirm email** (Шаг 1.3) и адрес сайта добавлен в **Redirect URLs** (Шаг 1.4). |
| Вход по почте работает локально, но не на сайте | Адрес сайта не добавлен в **Redirect URLs** в Supabase. |
| Ошибка поиска фильмов (401) | Неверный `TMDB_API_KEY` в `src/config.js`. |
| Поиск фильмов не отвечает / таймаут | Провайдер блокирует TMDb — включите прокси (Шаг 5). |
| Оценки не обновляются у друзей | Проверьте, что `supabase-schema.sql` запускался целиком: в конце скрипт добавляет таблицы в publication `supabase_realtime`. |
| После нового деплоя вижу старую версию | Обновите страницу (сервис-воркер использует network-first для страниц); на телефоне — закройте и откройте приложение заново. |
| Заставка «Загружаем…» висит вечно | Нет интернета или провайдер блокирует CDN (Tailwind / esm.sh). Через 12 секунд приложение само покажет подсказку с кнопкой «Повторить». |

## 📱 Как добавить приложение на главный экран телефона
- **Android:** откройте сайт в Chrome → три точки → **«Добавить на главный экран»** / «Установить приложение».
- **iOS:** откройте сайт в Safari → кнопка **«Поделиться»** → **«На экран «Домой»»**.

Приложение откроется в отдельном окне без панели браузера, со своей иконкой. Оболочка работает даже без сети (покажет последний кэш), данные синхронизируются при появлении интернета.

## 💡 Как пользоваться
1. Найдите фильм или сериал через поиск сверху — варианты показываются с постерами и годом.
2. В карточке поставьте оценку от 1 до 10, при желании добавьте комментарий.
3. Не смотрели? Добавьте в «Хочу посмотреть» — фильм появится в общем списке компании.
4. В ленте видны оценки всех друзей; фильтры позволяют смотреть только фильмы, только сериалы или только свои оценки.
5. В профиле — ваша статистика и списки. У администратора там же заявки на доступ и кнопка бэкапа.

```
├── index.html                 # Точка входа (PWA-мета, иконки, заставка загрузки)

├── _redirects                 # Фича Cloudflare Pages: SPA-роутинг (НЕ для Workers!)
├── _headers                   # Фича Cloudflare Pages: заголовки кэширования/безопасности
├── supabase-schema.sql        # Схема БД: таблицы, RLS, триггеры, реалтайм (идемпотентная)
├── icons/                     # Иконки PWA: 192/512, maskable, apple-touch, favicon
├── optional/
│   └── tmdb-proxy-worker.js   # Опциональный прокси TMDb для Cloudflare Workers
└── src/
    ├── main.js                # Точка входа приложения, маршрутизация состояний
    ├── config.js              # Ключи и настройки (anon key вставляется сюда)
    ├── components/
    │   ├── Auth.js            # Страница входа по магической ссылке
    │   ├── Setup.js           # Экраны-подсказки: не настроен конфиг / нет профиля / ошибка
    │   ├── AccessDenied.js    # Экран ожидания одобрения доступа
    │   ├── Feed.js            # Лента оценок, поиск, фильтры, реалтайм
    │   ├── RatingModal.js     # Карточка фильма: оценки друзей, своя оценка, watchlist
    │   └── Profile.js         # Профиль, статистика, админ-панель, бэкап
    └── lib/
        ├── supabase.js        # Клиент Supabase, работа с пользователем и профилями
        ├── tmdb.js            # Запросы к TMDb (поиск, детали; поддержка прокси)
        ├── ratings.js         # Оценки и «хочу посмотреть»
        ├── dom.js             # Экранирование HTML, аватары, тосты
        └── date.js            # Форматирование дат («5 мин назад»)
```

## 🛡️ Заметки о безопасности и приватности
- Все таблицы закрыты политиками RLS: данные круга друзей видны только одобренным участникам.
- Новый зарегистрированный пользователь **не видит ничего**, пока админ не одобрит его в один клик.
- Оценки, комментарии и watchlist пользователь может изменять только свои.
- Бэкап в JSON выгружается только у администратора и остаётся у вас на устройстве.

## 🤖 Опциональный Телеграм-бот
После запуска основного сайта можно добавить бота с уведомлениями о новых оценках и возможностью ставить оценки из Телеграма. Инструкция и код будут добавлены отдельно — на работу сайта бот не влияет.
