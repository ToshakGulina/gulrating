# 🎬 ГульРейтинг
Приложение для совместной оценки фильмов и сериалов в кругу друзей. Полностью бесплатное в использовании, не требует серверов и регулярных оплат, работает на любых устройствах из браузера, ставится на главный экран телефона как приложение (PWA) без публикации в App Store / Google Play.

## 📋 Что умеет
- ✅ Поиск фильмов и сериалов по базе TMDb (более 800 тыс. тайтлов) с автодополнением: постер и год, чтобы не перепутать одноимённые фильмы
- ✅ Автоматическая загрузка постера, года выхода, жанров, описания и рейтинга TMDb при добавлении фильма
- ✅ Общая лента оценок друзей с комментариями: видно, кто и когда поставил оценку
- ✅ Фильтры ленты: все оценки / только фильмы / только сериалы / мои оценки / «хочу посмотреть» всей компании + сортировка (новые / высокие сначала / низкие сначала, выбор запоминается)
- ✅ Карточка фильма: оценки всех друзей и средняя оценка в вашей компании
- ✅ Оценка 1–10 **с точностью до десятых** (7.5, 8.3): слайдер «как яркость на телефоне» + кнопки ±0.1, комментарий, изменение и удаление своей оценки
- ✅ История поиска: недавние запросы и недавно открытые фильмы/сериалы в один тап (хранится локально на устройстве, кнопка «Очистить»)
- ✅ Живой первый экран: приветствие по имени, мягкий градиентный фон, онбординг-подсказка и ряд «Сейчас в тренде» с постерами TMDb, пока в ленте ещё нет оценок
- ✅ Опциональный рейтинг Кинопоиска в карточке фильма (рядом с TMDb и средней оценкой друзей)
- ✅ Список «Хочу посмотреть» (добавление/удаление в один клик)
- ✅ Личный профиль со статистикой: количество оценок, средняя оценка, сколько в планах
- ✅ Система доступа: вход по магической ссылке на почту, администратор одобряет новых участников в один клик — посторонние не попадут
- ✅ Реалтайм: новые оценки появляются у всех сразу, без перезагрузки страницы
- ✅ PWA: установка на главный экран телефона (Android и iOS), работа офлайн (оболочка приложения)
- ✅ Бэкап всех данных в JSON в один клик для администратора
- ✅ Тёмная адаптивная вёрстка под телефоны, планшеты и компьютеры
- ✅ Опциональный прокси через Cloudflare Worker для TMDb (если api.themoviedb.org блокируется провайдером) и для Кинопоиска (см. `optional/proxy-worker.js`)
- ✅ Телеграм-бот: уведомления о новых оценках в чат компании, команды /top и /random (Pages Functions, без серверов)

## 🧰 Стек
- Ванильный HTML/CSS/JS + Tailwind CSS (без сборки: приложение загружается мгновенно)
- Supabase — база данных, авторизация по магическим ссылкам, реалтайм, политики доступа (RLS)
- TMDb API — база фильмов и сериалов
- Cloudflare Pages — бесплатный статический хостинг

## 🚀 Быстрый старт

### Что уже настроено в этом репозитории
| Параметр | Значение | Где лежит |
|---|---|---|
| Supabase Project URL | `https://ahpgxyfkbvuabgtrgacu.supabase.co` (регион Frankfurt) | `src/config.js` |
| TMDb API Key (v3) | вшит | `src/config.js` |
| Supabase anon key | **нужно вставить один раз** | `src/config.js` → `SUPABASE_ANON_KEY` |

> Пока anon key не вставлен, приложение не падает, а показывает экран-подсказку с инструкцией, какие поля заполнить.

### Шаг 1. База данных в Supabase (5 минут)
1. Откройте дашборд проекта Supabase → **SQL Editor** → **New query**.
2. Вставьте туда **весь** файл `supabase-schema.sql` и нажмите **Run**.
   Скрипт идемпотентный: его можно запускать повторно, ничего не сломается. Он создаёт таблицы `profiles`, `titles`, `ratings`, `watchlist`, политики RLS, триггер автоматического создания профиля, выдаёт права ролям и включает реалтайм.
   **Повторно запускайте скрипт после обновлений репозитория** — так в базу попадают миграции (например, тип оценки с десятыми долями).
3. **Authentication → Providers → Email** → выключите **Confirm email** → Save. Тогда и вход по магической ссылке, и регистрация с паролем работают сразу, без подтверждения письма (доступ всё равно регулирует одобрение администратором).
4. **Authentication → URL Configuration**:
   - **Site URL** — главный адрес сайта. Пока деплоя нет, поставьте `http://localhost:8000`; после шага 4 обязательно замените на `https://<имя-проекта>.pages.dev`. Магические ссылки и любые редиректы по умолчанию ведут именно на Site URL, поэтому оставленный `localhost:3000` уводит письма в никуда;
   - **Redirect URLs** — добавьте список разрешённых адресов:
     - `http://localhost:8000` — для локальных тестов;
     - адрес продакшена после деплоя (шаг 4);
     - адрес предпросмотра Arena/песочницы, если тестируете оттуда.
     Адрес, не попавший в этот список, Supabase молча заменяет на Site URL.
5. **Settings → API**: скопируйте **anon public** key.

### Шаг 2. Ключ в конфиге (1 минута)
В файле `src/config.js` замените плейсхолдер:
```js
SUPABASE_ANON_KEY: "сюда_вставьте_anon_key_из_supabase",
```
Это единственный ключ, который нужно вставить руками. URL Supabase и ключ TMDb уже вписаны.

> 💡 **Быстрый тест без правки кода:** если открыть сайт до вставки ключа, появится экран «Приложение не настроено» с полем, куда anon key можно вставить прямо из браузера — он сохранится в localStorage этого браузера. Это удобно для проверки и предпросмотра; для продакшена ключ всё равно впишите в `src/config.js`, чтобы он работал у всех друзей сразу.

> 🔐 **Почему ключ в коде — это нормально:** `anon` ключ Supabase задуман публичным. Реальную защиту данных обеспечивают политики RLS в базе (см. `supabase-schema.sql`): не одобренный админом пользователь не увидит ни одной оценки. То же касается ключа TMDb — это обычный ключ чтения каталога фильмов.

### Шаг 3. Локальный запуск (2 минуты)
```bash
npx serve .
# или, если нет node:
python3 -m http.server 8000
```
Откройте `http://localhost:8000`, введите почту и перейдите по присланной ссылке. **Первый зарегистрированный пользователь автоматически становится администратором** и получает доступ сразу. Друзьям достаточно ссылки на сайт: они попадут в список заявок, вы одобрите их в Профиле в один клик.

### Шаг 4. Деплой на Cloudflare Pages (3 минуты)

> ⚠️ **САМОЕ ВАЖНОЕ:** при подключении репозитория выбирайте **Cloudflare Pages (статический сайт)**, а **НЕ Cloudflare Workers**. Ошибка прошлого деплоя возникла именно из-за выбора типа Workers. Файлы `_redirects` и `_headers` в корне — это штатные фичи **Pages** (SPA-роутинг и заголовки кэширования); в Workers они не поддерживаются, поэтому там и была ошибка. Удалять их не нужно.

1. https://pages.cloudflare.com → **Sign up** через GitHub (бесплатно, карта не нужна).
2. **Create a project** → **Connect to Git** → выберите репозиторий `ToshakGulina/gulrating` и ветку, из которой деплоите (обычно `main`).
3. В настройках сборки укажите:
   - **Framework preset:** `None`
   - **Build command:** оставьте полностью пустым
   - **Output directory:** `/` (корень репозитория)
4. **Save and Deploy** — через минуту сайт будет доступен по адресу вида `gulrating.pages.dev`.
5. Вернитесь в Supabase → **Authentication → URL Configuration**:
   - **Site URL** замените на `https://gulrating.pages.dev` (иначе письма со ссылкой будут уводить на localhost);
   - в **Redirect URLs** добавьте `https://gulrating.pages.dev`.
   Без этого вход по почте на проде не сработает.

**Деплой из терминала (альтернатива):** если не хочется подключать Git в дашборде,
```bash
npx wrangler pages deploy . --project-name=gulrating
```
(воркер/секреты не нужны — это чисто статический деплой).

### Шаг 5 (опционально). Прокси: TMDb при блокировках и кэш Кинопоиска
Рейтинг Кинопоиска работает сразу: токен сервиса api.poiskkino.dev уже вписан в `src/config.js` (`KINOPOISK_API_KEY`, бесплатный лимит ~200 запросов в сутки). Прокси-воркер нужен только если захотите вынести токен из кода и кэшировать ответы на сутки (экономия лимита):
1. Создайте Worker в Cloudflare (Workers & Pages → Create → Worker), вставьте код из `optional/proxy-worker.js`, задеплойте.
2. В настройках воркера (Settings → Variables and Secrets) добавьте секреты:
   - `KINOPOISK_API_KEY` — токен api.poiskkino.dev;
   - `TMDB_API_KEY` — если нужен прокси для TMDb.
3. В `src/config.js` впишите адреса воркера с префиксами:
   - `KINOPOISK_PROXY_URL = "https://<имя>.workers.dev/kp"`;
   - `TMDB_PROXY_URL = "https://<имя>.workers.dev/tmdb"` (опционально; значения без префикса тоже работают).

**Про рейтинг Кинопоиска честно:** официального открытого API для физлиц у Кинопоиска нет, а прямые запросы к киносервисам из браузера часто блокируются CORS. Поэтому используется неофициальный сервис ПоискКино (poiskkino.dev, API `api.poiskkino.dev`, версия v1.5): токен бесплатно выдаёт ТГ-бот @poiskkinodev_bot, токен уже вписан в `src/config.js`. Запросы идут через прокси того же домена — `functions/kp/[[path]].js` (Pages Functions): он работает автоматически после деплоя на Cloudflare Pages и кэширует ответы на сутки на стороне Cloudflare, экономя лимит на всю компанию. Заодно из того же ответа берётся рейтинг IMDb (это другой сервис, не TMDb) и показывается отдельной строкой со своим логотипом. В локальном предпросмотре прокси нет, и приложение пробует прямой запрос — если сервис не отдаёт CORS, бейдж КП в предпросмотре не появится, а на задеплоенном сайте появится. При исчерпанном лимите или недоступности сервиса в карточке показываются TMDb и средняя оценка друзей — ничего не ломается.

## 🧯 Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| Белый экран / экран «Приложение не настроено» | Не заполнен `SUPABASE_ANON_KEY` в `src/config.js`. Вставьте ключ и обновите страницу. |
| Ошибка «permission denied for table profiles» (или ratings/titles/watchlist) | В новых проектах Supabase таблицы из SQL Editor по умолчанию закрыты от ролей anon/authenticated на уровне привилегий. Запустите в SQL Editor блок GRANT из `supabase-schema.sql` (раздел «Права доступа ролей Supabase») или весь скрипт целиком — он идемпотентен. RLS продолжает защищать строки, так что выдача табличных прав безопасна. |
| Экран «Профиль не создан» | Аккаунт появился до запуска `supabase-schema.sql` (триггер на старых пользователей не действует) или схема не запущена вовсе. Нажмите на экране кнопку «Создать мой профиль сейчас»; либо в SQL Editor: запустите `supabase-schema.sql` целиком и выполните `SELECT public.repair_missing_profiles();` |
| «Доступ ожидает подтверждения» | Так и задумано: админ должен одобрить вас в Профиле → Управление доступом. |
| Письмо со ссылкой не приходит | Проверьте «Спам». Убедитесь, что выключен **Confirm email** (Шаг 1.3) и адрес сайта добавлен в **Redirect URLs** (Шаг 1.4). |
| Ссылка из письма открывает localhost:3000 или чужой адрес | В Supabase → Authentication → URL Configuration **Site URL** не равен адресу сайта. Поставьте Site URL = `https://<имя>.pages.dev` и добавьте тот же адрес в Redirect URLs. |
| Вход по почте работает локально, но не на сайте | Адрес сайта не добавлен в **Redirect URLs** и/или **Site URL** в Supabase. |
| Ошибка поиска фильмов (401) | Неверный `TMDB_API_KEY` в `src/config.js`. |
| Поиск фильмов не отвечает / таймаут | Провайдер блокирует TMDb — включите прокси (Шаг 5). |
| В карточке нет рейтинга Кинопоиска | Токен api.poiskkino.dev не задан, исчерпан дневной лимит (~200/сутки) или сервис недоступен — показываются TMDb и средняя оценка друзей, это не ошибка. Проверьте `KINOPOISK_API_KEY` / `KINOPOISK_PROXY_URL` (Шаг 5). |
| Оценка сохраняется только целая | В базе старый тип колонки: повторно запустите `supabase-schema.sql` (Шаг 1), он переведёт `ratings.rating` в NUMERIC(3,1). |
| Оценки не обновляются у друзей | Проверьте, что `supabase-schema.sql` запускался целиком: в конце скрипт добавляет таблицы в publication `supabase_realtime`. |
| После нового деплоя вижу старую версию | Обновите страницу (сервис-воркер использует network-first для страниц); на телефоне — закройте и откройте приложение заново. |
| Заставка «Загружаем…» висит вечно | Нет интернета или провайдер блокирует CDN (Tailwind / esm.sh). Через 12 секунд приложение само покажет подсказку с кнопкой «Повторить». |

## 📱 Как добавить приложение на главный экран телефона
- **Android:** откройте сайт в Chrome → три точки → **«Добавить на главный экран»** / «Установить приложение».
- **iOS:** откройте сайт в Safari → кнопка **«Поделиться»** → **«На экран «Домой»»**.

Приложение откроется в отдельном окне без панели браузера, со своей иконкой. Оболочка работает даже без сети (покажет последний кэш), данные синхронизируются при появлении интернета.

## 💡 Как пользоваться
1. Найдите фильм или сериал через поиск сверху — варианты показываются с постерами и годом.
2. В карточке поставьте оценку от 1 до 10, при желании добавьте комментарий.
3. Не смотрели? Добавьте в «Хочу посмотреть» — фильм появится в общем списке компании.
4. В ленте видны оценки всех друзей; фильтры позволяют смотреть только фильмы, только сериалы или только свои оценки.
5. В профиле — ваша статистика и списки. У администратора там же заявки на доступ и кнопка бэкапа.

## 🛡️ Заметки о безопасности и приватности
- Все таблицы закрыты политиками RLS: данные круга друзей видны только одобренным участникам.
- Новый зарегистрированный пользователь **не видит ничего**, пока админ не одобрит его в один клик.
- Оценки, комментарии и watchlist пользователь может изменять только свои.
- Пользователь не может выдать себе администратора или одобрение: самосоздание профиля ограничено политикой INSERT (первый профиль в пустой базе — исключение, как и в триггере), а любые UPDATE привилегий не-админом откатывает триггер `protect_profile_privileges`.
- Бэкап в JSON выгружается только у администратора и остаётся у вас на устройстве.

## 🤖 Телеграм-бот (уведомления и команды)

Бот живёт целиком в Cloudflare Pages Functions (`functions/tg/[[path]].js`) — отдельный сервер, хостинг или Workers-проект не нужны и не оплачиваются. На работу сайта бот не влияет: если переменные не заполнены, эндпоинты отвечают инструкцией, а сайт просто не шлёт уведомления.

Возможности:
- уведомление в чат компании при каждой сохранённой оценке: «🎬 Имя оценил(а) «Название» на 7.5/10» + ссылка, открывающая карточку тайтла на сайте;
- команды в чате: `/top` (топ-5 тайтлов по средним оценкам компании), `/random` (случайный тайтл из оценённых), `/help`, `/start`;
- защита от посторонних: уведомление принимается только с живой Supabase-сессией сайта (проверяется access_token), команды с оценками отвечают только в настроенном чате.

Подключение (5 минут):
1. В [@BotFather](https://t.me/BotFather) создайте бота (`/newbot`) и скопируйте токен.
2. В Cloudflare Pages: **Settings → Environment variables** добавьте `TG_BOT_TOKEN`, `TG_CHAT_ID` (id чата компании: напишите там любое сообщение и узнайте id, например, через @userinfobot), `SUPABASE_URL`, `SUPABASE_ANON_KEY`. Задеплойте снова (переменные применяются на новом деплое).
3. Откройте `https://ваш-сайт/tg/setup` — функция сама зарегистрирует вебхук у Телеграма и покажет подтверждение.
4. В чате компании отправьте `/start` — бот подтвердит подключение. Готово: новые оценки начнут приходить автоматически.
